
# Industrial Fault Detection via Bernoulli Restricted Boltzmann Machine (RBM)

A deterministic, CPU-based industrial fault detection prototype built with pure Python, NumPy, and Matplotlib. The system uses a Bernoulli Restricted Boltzmann Machine trained with Contrastive Divergence (CD-1) and detects multi-sensor anomalies via analytical free-energy thresholding.

---

## 1. Project Overview

In industrial monitoring, continuous telemetry from sensors (temperatures, pressures, vibrations, currents) exhibits strong latent correlations under normal operating conditions. When physical faults or sensor degradation occur, the multi-sensor correlation structure breaks.

This project implements an unsupervised anomaly detection pipeline:
1. **Synthetic Industrial Telemetry**: Simulates 8 continuous sensor channels generated by 3 underlying latent Gaussian physical processes, mixed through a fixed linear transformation with additive Gaussian measurement noise ($\sigma = 0.05$).
2. **Min-Max Normalization**: Scales features to $[0, 1]$ based strictly on training bounds, safely handling zero-variance channels and clipping test deviations.
3. **Bernoulli Restricted Boltzmann Machine (RBM)**: An energy-based model with 8 visible and 5 hidden units trained exclusively on normal operational telemetry.
4. **Contrastive Divergence (CD-1)**: Trains the RBM using single-step Gibbs sampling with numerically stable activations and exact mini-batch gradient updates.
5. **Analytical Free Energy Detection**: Computes exact sample free energy via stable softplus formulation. Anomalies are flagged when free energy exceeds $\mu_{\text{train}} + 3\sigma_{\text{train}}$.
6. **Diagnostics & Reporting**: Evaluates classification performance (Precision, Recall, F1, Confusion Matrix) against injected ground-truth fault windows and outputs a dual-panel visualization (`anomaly_report.png`).

## 2. Mathematical Formulation

### 2.1 Energy Function
For visible configuration $v \in [0, 1]^V$ and binary hidden configuration $h \in \{0, 1\}^H$, the energy is:
$$E(v, h) = - \sum_{i=1}^V a_i v_i - \sum_{j=1}^H b_j h_j - \sum_{i=1}^V \sum_{j=1}^H v_i W_{ij} h_j$$
where:
- $W \in \mathbb{R}^{V \times H}$ is the pairwise interaction weight matrix.
- $a \in \mathbb{R}^V$ is the visible bias vector.
- $b \in \mathbb{R}^H$ is the hidden bias vector.

### 2.2 Conditional Distributions
Due to the bipartite structure of the RBM:
$$P(h_j = 1 \mid v) = \sigma\left( \sum_{i=1}^V v_i W_{ij} + b_j \right) = \sigma( (v W + b)_j )$$
$$P(v_i = 1 \mid h) = \sigma\left( \sum_{j=1}^H h_j W_{ij} + a_i \right) = \sigma( (h W^T + a)_i )$$
where $\sigma(z) = \frac{1}{1 + e^{-z}}$ is the numerically stable logistic sigmoid function.

### 2.3 Analytical Free Energy
The marginal probability of an observation $v$ is $P(v) = \frac{1}{Z} \sum_h e^{-E(v, h)} = \frac{1}{Z} e^{-F(v)}$.
Marginalizing over all $2^H$ hidden configurations yields the closed-form analytical free energy:
$$F(v) = - \sum_{i=1}^V a_i v_i - \sum_{j=1}^H \ln\left(1 + \exp\left(b_j + \sum_{i=1}^V v_i W_{ij}\right)\right)$$
Using the numerically stable softplus function $\text{softplus}(x) = \max(x, 0) + \ln(1 + e^{-|x|})$:
$$F(v) = - v a^T - \sum_{j=1}^H \text{softplus}\big((v W + b)_j\big)$$
Lower energy corresponds to higher likelihood under normal operating data. Anomalous or out-of-distribution inputs exhibit elevated free energy.

### 2.4 Contrastive Divergence (CD-1) Updates
Parameter gradients are approximated via Contrastive Divergence with one step of Gibbs sampling:
$$\Delta W = \frac{1}{B} \left( v^{(0)T} P(h^{(0)}=1 \mid v^{(0)}) - v^{(1)T} P(h^{(1)}=1 \mid v^{(1)}) \right)$$
$$\Delta a = \frac{1}{B} \sum_{k=1}^B \left( v^{(0)}_k - v^{(1)}_k \right)$$
$$\Delta b = \frac{1}{B} \sum_{k=1}^B \left( P(h^{(0)}_k=1 \mid v^{(0)}_k) - P(h^{(1)}_k=1 \mid v^{(1)}_k) \right)$$
where $B$ is the batch size (handling partial batches by dynamic size).

### 2.5 Anomaly Decision Boundary
The decision threshold $\tau$ is established strictly from normal training telemetry:
$$\tau = \mu\big(F(X_{\text{train}})\big) + 3 \times \sigma\big(F(X_{\text{train}})\big)$$
Anomalies are detected on test data when:
$$\hat{y}(v) = \mathbb{I}\big(F(v) > \tau\big)$$

## 5. Engineering Principles
- **Zero External Datasets**: Purely deterministic synthetic generation using `numpy.random.default_rng(seed)`.
- **Numerical Stability**: Prevents floating point underflow/overflow in sigmoid and softplus operations.
- **Strict Data Hygiene**: Scaling parameters and threshold $\tau$ are learned exclusively on normal training data without test label contamination.
- **Batch Precision**: Partial mini-batches use exact batch lengths during gradient accumulation.

## 6. Phase 2: Synthetic Data Generation & Preprocessing

The data generation module (`data_generator.py`) generates deterministic industrial sensor telemetry:
- **Latent Physics**: 3 independent standard-normal latent factors generate 8 continuous sensor channels through a fixed `(8, 3)` mixing matrix plus additive Gaussian noise ($\sigma = 0.05$).
- **Sample Distribution**: 2,000 normal training samples (`X_train`) and 500 test samples (`X_test`).
- **Data Scaling**: Min-Max normalization fitted strictly on `X_train`, safely protecting against zero-range features, and clipping transformed values to $[0.0, 1.0]$.
- **Fault Injection**: 70 ground-truth anomalies injected into `X_test` over two half-open intervals:
  - `[300, 350)` (50 samples): Sensor saturation and severe directional drift.
  - `[420, 440)` (20 samples): Severe uncorrelated noise spikes and erratic fluctuations.
- **Pristine Preservation**: Unmodified normal test data is preserved as `X_test_normal`.
- **Validation**: Verified through 9 unit tests in `test_data_generator.py` covering shapes, ranges, reproducibility, bounds, and strict isolation of training data.

## 7. Phase 3: Restricted Boltzmann Machine (RBM) & CD-1 Training

The RBM module (`rbm.py`) implements a fully vectorized, deterministic Bernoulli Restricted Boltzmann Machine:
- **Architecture**:
  - $V = 8$ visible units corresponding to normalized industrial sensor channels.
  - $H = 5$ hidden units capturing underlying operational latent structure.
  - Weight matrix $W \in \mathbb{R}^{5 \times 8}$ initialized from $\mathcal{N}(0, 0.01^2)$.
  - Visible bias vector $b \in \mathbb{R}^8$ initialized to zeros.
  - Hidden bias vector $c \in \mathbb{R}^5$ initialized to zeros.
- **Contrastive Divergence (CD-1)**:
  - 1 Gibbs sampling transition: $v^{(0)} \to h^{(0)} \to v^{(1)} \to h^{(1)}$.
  - Positive phase: $h^{(0)} \sim \text{Bernoulli}\big(\sigma(v^{(0)} W^T + c)\big)$.
  - Negative phase: $v^{(1)} \sim \text{Bernoulli}\big(\sigma(h^{(0)} W + b)\big)$, $h^{(1)}_{\text{prob}} = \sigma(v^{(1)} W^T + c)$.
  - Gradient updates:
    $$\Delta W = \frac{\eta}{B_{\text{actual}}} \left( h^{(0)T} v^{(0)} - h^{(1)T}_{\text{prob}} v^{(1)} \right)$$
    $$\Delta b = \frac{\eta}{B_{\text{actual}}} \sum_{k=1}^B (v^{(0)}_k - v^{(1)}_k)$$
    $$\Delta c = \frac{\eta}{B_{\text{actual}}} \sum_{k=1}^B (h^{(0)}_k - h^{(1)}_{k,\text{prob}})$$
  - Mini-batch handling: Mini-batches of 32 dynamically account for incomplete terminal mini-batches ($B_{\text{actual}} = 16$).
- **Hyperparameters**:
  - Visible Units: 8
  - Hidden Units: 5
  - Learning Rate: 0.01
  - Batch Size: 32
  - Epochs: 50
  - Random Seed: 42
- **Diagnostic Reconstruction MSE**:
  - Reconstruction error is computed analytically using visible reconstruction probabilities $p(v=1 \mid p(h=1 \mid X))$:
    $$\text{MSE} = \frac{1}{N \cdot V} \sum_{i=1}^N \sum_{j=1}^V (X_{ij} - \hat{v}_{ij})^2$$
  - *Note on MSE Dynamics*: In Contrastive Divergence, CD-1 approximates the log-likelihood gradient rather than optimizing reconstruction MSE directly. Reconstruction MSE serves as an unregularized diagnostic metric and may naturally oscillate or plateau rather than decrease monotonically.
- **Testing & Verification**:

## 8. Phase 4: Analytical Free-Energy Scoring & Anomaly Detection

The anomaly detection module (`anomaly_detector.py`) implements statistical fault detection based on analytical free energy:
- **Closed-Form Free Energy**:
  For an observation vector $v \in [0, 1]^V$:
  $$F(v) = - b^T v - \sum_{j=1}^H \text{softplus}\big(c_j + W_{j,:} v\big)$$
  Computed in NumPy via `np.logaddexp(0.0, z)` for numerical stability without Gibbs sampling.
- **Decision Threshold**:
  The threshold $\tau$ is derived exclusively from normal training observations:
  $$\tau = \mu\big(F(X_{\text{train}})\big) + 3 \times \sigma\big(F(X_{\text{train}})\big)$$
  where $\sigma$ is computed using population standard deviation (`ddof=0`). No test observations or labels are used during threshold computation.
- **Anomaly Decision Rule**:
  $$\hat{y}(v) = \begin{cases} \text{True (Anomaly)}, & \text{if } F(v) > \tau \\ \text{False (Normal)}, & \text{otherwise} \end{cases}$$
- **Evaluation Metrics**:
  Evaluates True Positives (TP), False Positives (FP), True Negatives (TN), False Negatives (FN), Precision, Recall, and F1-score with safe zero-denominator handling.
- **Empirical Performance Dynamics & Diagnosis**:
  Under the standard unilateral upper-bound threshold rule ($F(v) > \mu + 3\sigma$), anomalies are detected when their free energy is higher than normal telemetry. When industrial faults induce positive saturation (e.g. sensor values pinned near 1.0), the linear $-b^T v$ and softplus terms can drive $F(v)$ to become substantially *more negative* (lower free energy) than normal baseline operating points. Consequently, detection performance is empirical and sensitive to fault directionality relative to the learned energy surface.
- **Regression Testing**:
  ```bash
  python -m unittest -v test_data_generator.py test_rbm.py test_anomaly_detector.py
  ```

### 9.4 Physical and Mathematical Diagnosis of Current Detector Limitation
1. **Unilateral Upper-Tail Rule vs. Energy Shifts**:
   The baseline decision rule flags an anomaly solely when $F(v) > \tau$ (i.e. strictly elevated free energy).
2. **Impact of Sensor Saturation on Free Energy**:
   In our Bernoulli RBM formulation:
   $$F(v) = - b^T v - \sum_{j=1}^H \text{softplus}\big(c_j + W_{j,:} v\big)$$
   When sensors saturate near 1.0 (Fault Window 1), the linear visible term $-b^T v$ and softplus activations become large. Because the softplus terms are subtracted, $F(v)$ becomes **significantly more negative** (mean `-3.8207`) than normal telemetry (mean `-3.6139`).
3. **Implication**:
   The injected anomalies deviate strongly from the normal distribution, but they move into the **lower tail** of free energy ($F(v) < \mu - 3\sigma$) rather than the upper tail ($F(v) > \mu + 3\sigma$). Consequently, the strict unilateral upper threshold $\tau = -3.4407$ records zero detections (`FN = 70`, `TP = 0`), although False Positives are also zero (`FP = 0`).
4. **Preservation of Baseline Specification**:
   As mandated by engineering integrity rules, these empirical results are reported faithfully without adjusting the threshold rule using test data. A two-sided or bilateral threshold $|F(v) - \mu| > 3\sigma$ would be required to detect both energy spikes and energy depressions in subsequent research phases.

## 11. Phase 8: Channel-Wise Reconstruction Residuals for Industrial Fault Detection

Phase 8 investigates per-sensor reconstruction residuals to overcome the channel dilution effect inherent in scalar average mean squared error (MSE), enabling precise fault localization across the 8 industrial telemetry channels.

### 11.1 Motivation & Methodology

In Phase 7, average sample reconstruction MSE ($\frac{1}{V}\sum_j (X_{i,j} - \hat{X}_{i,j})^2$) achieved an F1-score of 0.8872 by capturing 50/50 Window 1 anomalies and 9/20 Window 2 noise spikes. However, averaging across all 8 channels dilutes localized disturbances when only a subset of sensors experience anomalies.

For each sample $i$ and sensor channel $j \in \{0, \dots, 7\}$, Phase 8 computes the deterministic squared reconstruction residual:
$$R[i, j] = \big(X[i, j] - \hat{X}[i, j]\big)^2$$
where $\hat{X} = \sigma(h W + b)$ is the deterministic probability-based visible reconstruction.

Using training residuals from normal telemetry ($R_{\text{train}}$), channel statistics are calculated strictly without test labels:
$$\mu_j = \frac{1}{N}\sum_{i=1}^N R_{\text{train}}[i, j], \quad \sigma_j = \sqrt{\frac{1}{N}\sum_{i=1}^N (R_{\text{train}}[i, j] - \mu_j)^2 + \epsilon}$$
with a numerical safeguard $\epsilon = 10^{-8}$ preventing division-by-zero.

Three unsupervised decision rules are evaluated:
1. **Method A (Per-Channel 3-Sigma Union)**:
   Flag channel $j$ if $R_{\text{test}}[i, j] > \mu_j + 3\sigma_j$.
   Flag sample $i$ if **at least one** channel is flagged ($\bigcup_j$).
2. **Method B (Per-Channel 99th Percentile Union)**:
   Compute $\tau_{j, 99} = \text{percentile}(R_{\text{train}}[:, j], 99)$ for each sensor.
   Flag channel $j$ if $R_{\text{test}}[i, j] > \tau_{j, 99}$.
   Flag sample $i$ if **at least one** channel is flagged.
3. **Method C (Maximum Normalized Residual Scoring / Top-1)**:
   For each sample, compute normalized channel residuals $z[i, j] = \frac{R[i, j] - \mu_j}{\sigma_j}$ and sample score:
   $$\text{score}[i] = \max_{j} z[i, j]$$
   Compute sample-level threshold $\tau_{C, 99} = \text{percentile}(\text{score}_{\text{train}}, 99)$.
   Flag sample $i$ if $\text{score}_{\text{test}}[i] > \tau_{C, 99}$.

#### Key Diagnostic Insights:
- **Fault Subsystem Partitioning**:
  - Fault Window 1 `[300, 350)` (sensor drift/saturation) concentrates energy strictly in **even channels** (0, 2, 4, 6), elevating residuals by 5.4× to 9.1× above normal operating levels.
